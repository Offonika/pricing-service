# Workflow: pricing-data

Использовать для импорта, очистки, нормализации, маппинга, витрин и качества внешних
данных из 1С, файлов и интеграций.

## Контекст

- Основные пути: `app/services/importers/`, `app/workers/`, профильные services,
  `tasks/`, `scripts/`, `tests/`.
- Сверить профильный integration contract, `docs/1c_sql_mapping.md` или spec,
  возвращённый root-router.
- Найти реальные parser/transform/load функции и fixtures; не читать большую выгрузку
  целиком.

## Действия

1. Зафиксировать входную схему, кодировку, ключи дедупликации и политику null/error.
2. Отделить чтение источника, нормализацию и запись результата.
3. Сделать повторный запуск идемпотентным либо явно описать ограничения.
4. Логировать количество принятых, отклонённых и неоднозначных строк без PII/секретов.
5. Изменение хранения оформить миграцией и согласовать с архитектурным workflow.

## Ограничения и проверки

- Доступ к 1С по умолчанию read-only; не изменять источник без утверждённого контура.
- Не подменять правила ценообразования преобразованием данных.
- Проверить малый fixture, ошибки и повторы, профильные тесты, Ruff и Black.
