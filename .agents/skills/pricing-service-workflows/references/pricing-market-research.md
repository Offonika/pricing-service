# Workflow: pricing-market-research

Использовать для официальных анонсов моделей устройств, генерации поисковых фраз и
получения метрик спроса через утверждённые backend-инструменты.

## Контекст

- Читать `docs/agents-market-research.md`, `docs/TechDesign.AgentsMarketDemand.md` и
  профильный PRD-раздел, если их вернул root-router.
- Основные пути: `agents/`, `config/agents/`, `app/services/market_research/` и tests.
- Проверить актуальный backend contract для models, keywords и demand fetch.

## Действия

1. Фиксировать официальный источник, URL и дату релиза модели.
2. Нормализовать производителя/модель детерминированно и сохранять provenance.
3. Использовать backend endpoints/tools вместо локальной БД или прямого SQL.
4. Генерировать фразы по версионируемым шаблонам и логировать принятые решения.
5. Батчи делать ограниченными, повторяемыми и наблюдаемыми.

## Ограничения и проверки

- Не парсить Wordstat напрямую; использовать официальный API Директа через backend.
- Не записывать напрямую в БД и не запускать платные/live запросы без разрешения.
- Проверить mocked tool calls, нормализацию, дедупликацию, логирование источников и
  профильные tests.
