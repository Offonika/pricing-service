# Доменные модули pricing-service

Это целевые границы модульного монолита. Новая бизнес-логика добавляется в
соответствующий пакет; существующие API и services переносятся сюда постепенно,
с сохранением внешних HTTP-маршрутов и совместимых импортов.

Внутри домена используются слои `api`, `application`, `domain`, `repositories`
и `contracts`. Доменный и application-код не импортирует FastAPI, а доступ к
внутренним модулям соседнего домена запрещён.
