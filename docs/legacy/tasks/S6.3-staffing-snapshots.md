# S6.3 — Реализовать staffing snapshots и периодические витрины укомплектованности

## Цель
Построить на сервере `A` витрины по укомплектованности персонала на основе графика `Bitrix24`, HR-справочника и, при наличии, факта выхода.

## Что нужно сделать
- Добавить сущности для:
  - сотрудников;
  - ролей и подразделений;
  - смен и назначений;
  - snapshots укомплектованности.
- Реализовать sync графика и оргструктуры из `Bitrix24`.
- Реализовать загрузку HR-статусов: активен, уволен, дата увольнения, руководитель.
- Считать daily snapshot:
  - план;
  - факт;
  - дефицит;
  - дефицит по ролям;
  - критичность по магазину/смене.
- Считать period summary:
  - средняя укомплектованность;
  - дни с провалом;
  - повторяющийся некомплект;
  - прогноз дефицита на 3/7/14 дней.

## Артефакты/файлы
- Модели / миграции staffing-контура.
- Сервисы sync и расчёта snapshots.
- Витрины или materialized views для daily/period summary.
- Тесты расчёта укомплектованности.

## Definition of Done
- На выбранную дату можно получить daily staffing snapshot по магазинам и сменам.
- Периодические summary считаются из исторических snapshots, а не из live-данных.
- Уволенные сотрудники и смена статусов учитываются корректно.
- Есть тесты на некомплект, повторяющийся дефицит и смену статуса сотрудника.
