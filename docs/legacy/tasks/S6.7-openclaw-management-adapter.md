# S6.7 — Интеграционный adapter в Openclaw для чтения management API сервера A

## Цель
Подключить существующий `Openclaw`-контур на сервере `B` к management API сервера `A`, чтобы утренние отчёты собирались из звонков/Bitrix24/чатов и готовых управленческих витрин одновременно.

## Что нужно сделать
- Реализовать на `B` adapter-клиент для чтения management API сервера `A`.
- Настроить авторизацию service-to-service токеном.
- Добавить тайм-ауты, retry policy и понятную деградацию, если `A` недоступен.
- Встроить management payload в текущий pipeline утренних отчётов `Openclaw`.
- Разделить обязательные и опциональные блоки отчёта:
  - звонки / чаты / задачи;
  - дебиторка;
  - staffing;
  - AI action items по встречам.
- Задокументировать переменные окружения, расписание и порядок диагностики.

## Артефакты/файлы
- Скрипты / skill / config в `Openclaw`-контуре сервера `B`.
- Обновление конфигурации утренних отчётов.
- Документация по интеграции `A -> B`.
