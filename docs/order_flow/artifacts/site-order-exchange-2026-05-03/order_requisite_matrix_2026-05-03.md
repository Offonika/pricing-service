# Матрица реквизитов заказа сайта и 1С

Дата сбора: `2026-05-03`.

Назначение: зафиксировать, какие реквизиты участвуют в цепочке `сайт -> 1С УТ 10.3 -> сайт`, где сейчас смешаны доставка/оплата/исполнение и как разнести их в To-Be.

## Ключевой вывод

Текущий `осиСтатус` подтвержденно является смешанным полем: в одном справочнике лежат этапы (`Сборка товара`, `Ожидает вывоз`), финалы (`Завершен`, `Отменен`), способы доставки (`Самовывоз`, `СДЭК`, `ПОЧТА РОССИИ`, `ДОСТАВИСТА`) и коммуникационные состояния (`Ждём оплату`, `Ждём ответа`). Поэтому новый контур должен разделить `СтатусИсполнения`, `СтатусОплаты` и `СпособДоставки`.
