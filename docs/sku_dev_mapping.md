# Приложение A. Таблица соответствия DEV

Документ дополняет [положение по SKU](/opt/pricing-service/docs/sku_policy.md) и фиксирует базовые правила кодирования `DEV` для основных брендов.

Это рабочий справочник для каталога и разработки:

- использовать как ориентир при заведении новых товаров;
- при спорных кейсах приоритет у согласованного `DEV` из этого документа;
- список не исчерпывающий и может расширяться.

## Общие правила

- `DEV` кодируется латиницей и цифрами, без пробелов.
- Код должен быть коротким, но однозначным.
- Для семейств допускается один `DEV`, если это действительно одна совместимая платформа.
- Если это разные устройства, `DEV` должен различаться, даже если товары внешне близки.

## Примечания

- Если один и тот же модуль/аккумулятор реально подходит к нескольким моделям, допускается семейный `DEV`.
- Если это разные устройства и разные товарные позиции, `DEV` должен быть разведен.
- Для редких или новых моделей, которых нет в таблице, код утверждается по аналогии с существующими шаблонами.
