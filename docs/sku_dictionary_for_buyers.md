# Приложение B. Словарь расшифровки SKU для закупки

Документ дополняет [положение по SKU](/opt/pricing-service/docs/sku_policy.md) и [таблицу DEV](/opt/pricing-service/docs/sku_dev_mapping.md).

Назначение документа:

- помочь закупщикам и каталогу быстро читать SKU без обращения к разработчику;
- дать единые расшифровки коротких кодов;
- снизить ошибки при заведении новых карточек и проверке инвойсов.

## 1. Как читать SKU

Базовая схема:

`<BR>-<CAT>-<DEV>-<KEY>-<REV?>`

Пример:

`OEM-DSP-IPH13PM-OLD-BLK-RF`

Расшифровка:

- `OEM` — безбренд / прочее
- `DSP` — дисплей
- `IPH13PM` — iPhone 13 Pro Max
- `OLD-BLK-RF` — OLED, черный, переклейка / refurbished

Ещё пример:

`OEM-BAT-SMG-A705-4500-OR-SP`

Расшифровка:

- `OEM` — безбренд / прочее
- `BAT` — аккумулятор
- `SMG-A705` — Samsung A705
- `4500` — ёмкость 4500 mAh
- `OR-SP` — оригинальный сервисный вариант / service pack

## 2. Словарь BR

| Код | Значение |
| --- | --- |
| `F5` | F5ENERGY |
| `OFN` | Offonika |
| `OEM` | Безбренд / прочее |

## 3. Словарь CAT

| Код | Категория |
| --- | --- |
| `BAT` | Аккумуляторы |
| `DSP` | Дисплеи / экранные модули |
| `GLS` | Стекла / линзы / тач |
| `CBL` | Кабели |
| `CHR` | Зарядные устройства |
| `CAM` | Камеры |
| `FLX` | Шлейфы |
| `IC` | Микросхемы |
| `PRT` | Прочие запчасти |
| `SET` | Наборы / комплекты |

## 4. Что такое DEV

`DEV` — это код устройства или семейства устройств.

Примеры:

- `IPH11` — iPhone 11
- `IPH13PM` — iPhone 13 Pro Max
- `SMG-A705` — Samsung Galaxy A70
- `XMI-RN13P4` — Xiaomi Redmi Note 13 Pro 4G
- `HWE-P40LT` — Huawei P40 Lite
- `ONE-NORD` — OnePlus Nord

Полная таблица основных кодов лежит в документе [sku_dev_mapping.md](/opt/pricing-service/docs/sku_dev_mapping.md).

## 5. Словарь KEY для аккумуляторов

Для `BAT` ключевая часть обычно означает ёмкость или код батареи.

### 5.1. Ёмкость

| Пример | Значение |
| --- | --- |
| `3470` | 3470 mAh |
| `4500` | 4500 mAh |
| `5000` | 5000 mAh |

### 5.2. Повышенная ёмкость

| Код | Значение |
| --- | --- |
| `HC3470` | Повышенная ёмкость 3470 mAh |
| `HC` | High Capacity, если точная ёмкость не подтверждена |

### 5.3. Код батареи вместо ёмкости

Используется, если в данных нет надёжной ёмкости.

| Пример | Значение |
| --- | --- |
| `A1527` | Код батареи Apple |
| `EB-BS901ABY` | Код батареи Samsung |
| `HB476489EFW` | Код батареи Huawei |
| `BLP923` | Код батареи OPPO / OnePlus |

## 6. Словарь KEY для дисплеев

Для `DSP` ключевая часть обычно собирается как:

`ТЕХНОЛОГИЯ-ЦВЕТ-ГРЕЙД`

Пример:

`INL-BLK-CPM`

Расшифровка:

- `INL` — In-Cell
- `BLK` — черный
- `CPM` — copy medium

### 6.1. Тип дисплея / технология

| Код | Значение |
| --- | --- |
| `INL` | In-Cell |
| `OLD` | OLED |
| `HLD` | Hard OLED |
| `SLD` | Soft OLED |
| `AMD` | AMOLED |
| `IPS` | IPS |
| `PLS` | PLS |
| `TFT` | TFT |
| `COF` | COF |
| `COG` | COG |
| `STD` | Базовый fallback, когда тип не был определён точнее |

### 6.2. Цвет

| Код | Значение |
| --- | --- |
| `BLK` | Черный |
| `WHT` | Белый |
| `GRY` | Серый |
| `SLV` | Серебристый |
| `GLD` | Золотистый |
| `BLU` | Синий |
| `GRN` | Зеленый |
| `PNK` | Розовый |
| `PRP` | Фиолетовый |
| `ORG` | Оранжевый |
| `BGE` | Бежевый |
| `CLR` | Прозрачный / clear |

### 6.3. Грейд / класс

| Код | Значение |
| --- | --- |
| `OR` | Original |
| `OR1` | ORIG100 |
| `RF` | Refurbished / переклейка |
| `CPH` | Copy High |
| `CPM` | Copy Medium |
| `CPL` | Copy Low |
| `BTK` | Биток / снятый / с разбора |

## 7. Словарь REV

`REV` — это дополнительный суффикс. Он появляется только если без него нельзя различить две отдельные карточки.

### 7.1. Частые REV для дисплеев

| Код | Значение |
| --- | --- |
| `JK` | Серия модуля JK |
| `GX` | Серия модуля GX |
| `FOG` | Серия модуля FOG |
| `MNK` | Серия модуля MNK |
| `ZY` | Серия модуля ZY |
| `AG` | Серия модуля AG |
| `SL` | Серия модуля SL |
| `ALS` | Вариант с ALS-шлейфом |
| `SP` | Service Pack |
| `FR` | В рамке |
| `FF` | Full Size |
| `FS` | Small Size / frame-service short code, в зависимости от категории |
| `IN` | Внутренний экран |
| `OT` | Внешний экран |
| `PM` | PaperMatte |
| `42` / `44` / `46` | Размер часов в мм |

### 7.2. Частые REV для аккумуляторов

| Код | Значение |
| --- | --- |
| `PR` | Premium |
| `OR` | Original |
| `SP` | Service Pack |
| `OR-SP` | Оригинальный сервисный вариант |
| `HC-NF` | High Capacity, без шлейфа |
| `SD` | System Diagnosable |
| `NF` | No Flex / без шлейфа |
| `CK` | В кейс / в зарядный кейс |
| `DC` | С доп. контроллером / variant code |
| `SN` | Service / serial commercial variant |
| `DJ` | DEJI |
| `F5` | F5ENERGY variant |
| `EXY` | Exynos-вариант |
| `RP` | Обратная полярность |

## 9. Как пользоваться словарём закупщику

1. Разбить SKU по дефисам.
2. Определить `BR` и `CAT`.
3. Найти `DEV` в [sku_dev_mapping.md](/opt/pricing-service/docs/sku_dev_mapping.md).
4. Сверить `KEY` по правилам своей категории:
   - для аккумуляторов — ёмкость / battery code;
   - для дисплеев — тип / цвет / грейд.
5. Если есть хвост после основного SKU, проверить `REV` по таблице выше.

## 10. Что не должен делать закупщик

- Не придумывать новые сокращения вручную.
- Не смешивать в `DEV` название модели и коммерческий комментарий.
- Не использовать `REV`, если это не отдельная карточка.
- Не заменять утверждённые коды свободным текстом.

## 11. Когда эскалировать в каталог / разработку

- если новый товар не укладывается в текущую схему `DEV`;
- если один и тот же SKU получается у двух реально разных карточек;
- если неясно, является ли отличие отдельной номенклатурой или просто описанием;
- если в карточке отсутствуют ключевые атрибуты для `KEY`.
