# Weekly digest (еженедельный обзор новинок смартфонов)

## Формат текста (Markdown)
- Файл: `data/digests/weekly/YYYY-MM-DD.md`
- Разделы:
  - `# Главная новость` — заголовок и 2–3 предложения о ключевом событии недели.
  - `## Другие новинки` — 3–4 пункта вида `- Бренд Модель — статус, источник, 1 предложение`.
  - `## Источники` — список ссылок на оригинальные материалы.
  - (опционально) `## Комментарий редактора` — короткий вывод или дисклеймер.
- Перед публикацией допускается ручное редактирование Markdown в любом редакторе.

## Картинка-анонс (PNG)
- Файл: `data/digests/weekly/YYYY-MM-DD.png`
- Поля для рендера:
  - Заголовок главной новости.
  - Бренд/модель и статус (анонс/слух/в продаже).
  - Короткий буллет (до 80–100 символов).
  - Дата недели.
  - Фон/цветовая тема: использовать базовые корпоративные цвета (уточнить у дизайнера) или нейтральный светлый фон; логотип, если есть.
- Генерация через скрипт (Pillow или другой рендер), без ручной правки PNG.

## Публикация
- Базовый вариант: отправка в Telegram:
  - `sendPhoto` — PNG-анонс (сгенерирован, а также обложка из OpenAI Images, если доступна).
  - `sendDocument` — файл `.md` или конвертированный `.pdf`, если нужен финальный формат.
  - `sendMessage` — короткий тизер (<= 4096 символов) с ссылкой на файл или пометкой "файл ниже".
- Если нужен HTTP-доступ к файлам, добавить endpoint `GET /digests/weekly/<date>` (читает из `data/digests/weekly`).

## Чек-лист перед отправкой
- [ ] Markdown сформирован в `data/digests/weekly/YYYY-MM-DD.md` и при необходимости отредактирован.
- [ ] PNG-анонс сгенерирован и отражает главную новость недели.
- [ ] Обложка сгенерирована через OpenAI Images (файл `...-cover.png`), если включена.
- [ ] Текст тизера укладывается в 4096 символов.
- [ ] Токены/чат в окружении заданы (`SMARTPHONE_RELEASES_ALERT_TELEGRAM_TOKEN`, `SMARTPHONE_RELEASES_ALERT_TELEGRAM_CHAT_ID`).
 - [ ] Установлен `pillow` (рендер PNG для weekly).
