# Task: S4.X — UI для ручного сопоставления товаров с конкурентами

Recommended Agent: pricing-backend

## Цель
Сделать веб-SPA для оператора: таблица наших товаров (тысячи позиций) + панель кандидатов конкурентов, действия «принять/снять/отклонить» привязку, поиск и фильтры. Основа — техдизайн `docs/TechDesign.CompetitorMatchingUI.md`.

## Требования
- Веб SPA (React + TS + Vite), AG Grid Community, React Query, Zustand; минимальные стили.
- Серверная пагинация/фильтры/сортировки, виртуализация строк, hotkeys.
- Панель кандидатов с lazy-load, live search по конкурентам (debounce).
- Действия: принять матч, снять матч, отклонить кандидата (чтобы не предлагать повторно).
- Массовое применение авто-пар выше порога.
- Статусы матчинга: none / auto / manual / ambiguous / uncertain / multiple.
- Ошибки/валидация в едином формате.
- Тосты/спиннеры, optimistic updates.
- Настроить CORS/авторизацию (минимально — token/basic), фича-флаг включения.

## Backend (чеклист)
- Реализовать эндпоинты из `docs/TechDesign.CompetitorMatchingUI.md` (GET products, GET candidates, POST match, DELETE match, POST reject, search competitors).
- Фильтры: статус, brand, category, search по name/sku.
- Учёт отклонённых кандидатов (не предлагать в top-N, кроме явного поиска).
- Аудит: кто/когда принял/снял/отклонил, reason.
- RPS-лимит для поиска (если нужно).
- Фича-флаги: включение UI/эндпоинтов, порог автопринятия.

## Frontend (чеклист)
- Vite + React + TS, AG Grid Community, React Query, Zustand.
- Components: ProductsGrid, CandidatePanel, BulkActionsBar, Progress/Stats.
- State в URL (page/sort/filters/productId).
- Hotkeys: ↑/↓ навигация; Enter — открыть/принять; Esc — закрыть панель; Backspace — снять (с подтверждением); Ctrl/Cmd+F — фокус на поиск.
- Optimistic updates для accept/revoke; debounced search.
- Тесты: рендер грида, загрузка кандидатов, accept/revoke с mock API.

## DoD
- SPA поднимается локально (README: как запустить, env для API URL).
- Все перечисленные эндпоинты реализованы и документированы (Swagger/OpenAPI).
- Статусы матчинга отображаются в гриде; действия работают.
- Отклонённые кандидаты не предлагаются повторно (кроме поиска).
- CI: линтеры/тесты проходят.
