# S6.11 — BI-витрина недельных продаж и выручки

## Цель
Собрать в БД витрину для отслеживания KPI по неделям: выручка и количество продаж с детализацией по менеджерам и подразделениям.

## Что нужно сделать
- Добавить DB view с недельной агрегацией на базе `receivable_ledger_event` только по событиям `sale`.
- Зафиксировать показатели:
  - `week_start`
  - `week_end`
  - `manager_ref`, `manager_name`
  - `store_ref`, `store_name`
  - `revenue`
  - `sales_count`
- Добавить read-only API для чтения витрины с фильтрами по периоду, менеджеру и подразделению.
- Покрыть happy path тестами.
