# S6.12 — Daily-витрина продаж как базовый слой KPI

## Цель
Сделать базовую ежедневную витрину продаж, от которой можно считать недельные и месячные KPI при отправке в чат и в BI.

## Что нужно сделать
- Добавить DB view `vw_bi_sales_daily_kpi`.
- Добавить read-only API `/api/bi/sales-daily-kpi`.
- Сохранить зерно `день × менеджер × подразделение`.
- Оставить weekly/monthly как производные агрегаты поверх daily.

## Показатели
- `sales_date`
- `manager_ref`, `manager_name`
- `store_ref`, `store_name`
- `revenue`
- `sales_count`

## Definition of Done
- Daily-витрина доступна в БД и через API.
- По daily можно собрать weekly/monthly KPI без отдельного хранения этих срезов.
- Есть тест на ежедневную агрегацию и фильтры.
