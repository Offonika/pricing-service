# ИсправлениеНДС: что делать Андрею

Ошибка `Неверный формат хранилища данных` означает, что 1С не смогла открыть сам
файл `ИсправлениеНДС.epf`. Это не ошибка расчета НДС.

Что сделать:

1. Открыть конфигуратор той же платформы, где запускается УТ 10.3: `1С 8.2`.
2. Создать новую внешнюю обработку.
3. Вставить `vat_included_fix_object_module.bsl` в модуль объекта.
4. Создать обычную форму и реквизиты:
   - `ФайлСписка` - строка;
   - `ФайлЛога` - строка;
   - `ТолькоПроверка` - булево;
   - `ПерепроводитьПроведенные` - булево;
   - `КонтролироватьСумму` - булево;
   - `ДопустимоеОтклонение` - число;
   - `МаксимумДокументов` - число;
   - `ОбрабатыватьНепроведенные` - булево.
5. Добавить кнопки с обработчиками:
   - `ВыбратьФайлСпискаНажатие`;
   - `ВыбратьФайлЛогаНажатие`;
   - `ВыполнитьНажатие`.
6. Вставить `vat_included_fix_form_module.bsl` в модуль формы.
7. Сохранить как новый файл, например `ИсправлениеНДС_УТ82.epf`.
8. Запустить сначала с `ТолькоПроверка = Истина` и `МаксимумДокументов = 1`.

Контрольный пример: `РБГУ0353446` должен провериться как изменение суммы
`1575 -> 1500`.
